Project 2 ระบุให้ส่ง `.tar.gz` และรวมโบนัสไว้แล้ว

[manifest.json](manifest.json) บันทึก SHA-256 ของ archive และไฟล์ต้นฉบับแต่ละตัว
ดู [ผลตรวจและข้อจำกัด](../docs/VALIDATION_TH.md) และ [รายงาน PDF](../project2/report.pdf)

ชื่อผู้จัดทำยังเว้นว่างตามข้อกำหนดของงานชุดนี้
ก่อนส่งจริงให้ตรวจชื่อ/รหัสที่รายวิชาต้องการ จำนวนสมาชิก วันส่ง และช่องทางส่ง
หากแก้โค้ดหรือรายงาน ต้องสร้างชุดส่งใหม่ด้วย `python scripts/package_submissions.py`
สคริปต์นี้จัดไฟล์ในเครื่อง ไม่ได้ส่งให้อาจารย์
